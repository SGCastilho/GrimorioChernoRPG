# Regressão Foundry — Fase 11.1

Este diretório contém os cinco bundles usados para validar a primeira camada de automação mecânica de características no Grimório Importer 0.7.0.

Classes representativas: Bárbaro, Guerreiro, Ladino, Monge e Paladino. O validador `tools/validate-foundry-phase11-module.js` materializa os cinco bundles em packs mock, verifica Activities, usos, recuperação, consumo de recursos, fórmulas e reimportação sem duplicações.

A Fase 11.1 não cria Active Effects. Características condicionais ou que dependem de contexto de combate permanecem com automação parcial ou somente descrição.
